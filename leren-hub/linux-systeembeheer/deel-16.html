01

Het probleem dat tmux oplost

⏱ 8 min

Milan draait een nachtelijke batchcontrole op het Rapportagecluster: een script dat een uur lang de aanlevering van mutatiebestanden bewaakt en foutmeldingen wegschrijft naar een logbestand. Hij start het script via SSH vanaf zijn laptop, loopt naar de koffieautomaat, en zijn laptop gaat na tien minuten in slaap. De SSH-verbinding valt weg — en daarmee ook het script, want het draaide in de voorgrond van die ene shell-sessie.

Dit is het probleem dat een terminal multiplexer oplost. Tmux (terminal multiplexer) laat processen draaien binnen een sessie die losstaat van de SSH-verbinding waarmee u hem bereikt. U start een sessie op de server, koppelt hem los (detach) zonder hem te stoppen, sluit uw laptop, en op een later moment — vanaf een ander toestel als het moet — koppelt u weer aan (attach) en ziet u precies de terminal zoals u hem achterliet, inclusief alle output die intussen is verschenen.

Fenna's vuistregel

"Alles wat langer draait dan de tijd die je zeker weet dat je verbonden blijft, start je in tmux. Op een server twijfel je altijd, dus start je het altijd in tmux."

Naast dat losstaan van de verbinding biedt tmux een tweede voordeel: één terminalvenster opdelen in meerdere windows en panes, zodat u bijvoorbeeld in het ene deelvenster een logbestand volgt en in het andere commando's uitvoert — zonder tussen meerdere SSH-sessies te hoeven schakelen.

02

Sessies starten, loskoppelen, hervatten

⏱ 10 min

Een nieuwe, benoemde sessie starten:

tmux new -s batchcontrole

De naam (batchcontrole) is optioneel maar sterk aan te raden — een naamloze sessie heet dan een nummer, en op een server met meerdere lopende sessies is dat onoverzichtelijk.

Loskoppelen zonder de sessie te stoppen: de toetscombinatie is standaard Ctrl+b, gevolgd door d (detach). U ziet dan weer de gewone shell-prompt, en de sessie blijft op de achtergrond draaien.

Lopende sessies bekijken:

tmux ls

Een sessie weer hervatten:

tmux attach -t batchcontrole

(kort: tmux a -t batchcontrole). Zit u al in een andere tmux-sessie en wilt u wisselen, dan koppelt u eerst los en attacht u opnieuw, of gebruikt u tmux switch -t <naam> binnen tmux zelf.

Een sessie definitief stoppen (het proces erin wordt beëindigd):

tmux kill-session -t batchcontrole
Casus

Milan start zijn batchcontrole zo:

tmux new -s batchcontrole
./bewaak_aanlevering.sh
# Ctrl+b, dan d

Hij logt uit, loopt naar de koffieautomaat, en logt een half uur later opnieuw in op het Rapportagecluster:

tmux attach -t batchcontrole

Het script draait onverstoord door en de output staat gewoon op het scherm.

Controlevraag

Uit Werkboek deel 16, Opdracht 16.1

1Start een tmux-sessie met de naam oefening, start daarin top, koppel de sessie los zonder top te stoppen, controleer met tmux ls dat de sessie nog bestaat, en koppel opnieuw aan om top af te sluiten.Toon antwoord
tmux new -s oefening
top
# Ctrl+b, dan d
tmux ls
# oefening: 1 windows (created ...)
tmux attach -t oefening
# in top: q om af te sluiten
03

Windows en panes

⏱ 10 min

Binnen één tmux-sessie kunt u meerdere windows hebben (vergelijkbaar met tabbladen) en elk window opdelen in meerdere panes (deelvensters).

Nieuw window aanmaken: Ctrl+b c. Wisselen tussen windows: Ctrl+b n (next), Ctrl+b p (previous), of direct naar nummer met Ctrl+b 0 tot Ctrl+b 9. Een overzicht van alle windows: Ctrl+b w.

Een pane verticaal splitsen (naast elkaar): Ctrl+b %. Horizontaal splitsen (boven/onder elkaar): Ctrl+b ". Tussen panes bewegen: Ctrl+b gevolgd door een pijltoets. Een pane groter maken: Ctrl+b gevolgd door Ctrl+pijltoets (herhaald indrukken vergroot verder). Een pane sluiten: typ exit in die pane, of Ctrl+b x en bevestig met y.

Casus

Fenna laat Milan tijdens een storing drie panes opzetten in één window: linksboven journalctl -u rapportage-agent -f om logs live te volgen, rechtsboven htop om resourcegebruik te zien, en onder een pane om zelf commando's uit te voeren. Zo hoeft hij niet drie keer via SSH in te loggen om hetzelfde beeld te krijgen.

tmux new -s storing
# Ctrl+b %        (verticale split)
# Ctrl+b "         (in de rechterhelft nogmaals horizontaal splitsen)
Controlevraag

Uit Werkboek deel 16, Opdracht 16.2

1Bouw in een nieuwe sessie dashboard de volgende indeling: window 1 met twee panes naast elkaar (links journalctl -f, rechts htop) en window 2 met één vrije pane. Wissel minstens drie keer tussen windows en panes zonder de muis te gebruiken.Toon antwoord
tmux new -s dashboard
# Ctrl+b %          -> verticale split
journalctl -f        # linkerpane
# Ctrl+b pijl-rechts -> naar rechterpane
htop
# Ctrl+b c           -> nieuw window (window 2)
# Ctrl+b 0 / Ctrl+b 1 -> wisselen tussen windows

Controlepunt: tmux list-windows toont twee windows; Ctrl+b w geeft een overzicht.

04

Copy mode: scrollen en kopiëren zonder muis

⏱ 8 min

Standaard scrollt de muis in een tmux-pane niet door de geschiedenis zoals in een gewone terminal. Daarvoor is copy mode: Ctrl+b [ activeert copy mode, waarna u met de pijltoetsen (of PageUp/PageDown) door de buffer kunt scrollen. Tekst selecteren doet u door op de startpositie Space in te drukken en naar het einde te bewegen; Enter kopieert de selectie naar de tmux-plakbuffer. Verlaten van copy mode zonder te kopiëren: q. Plakken van de laatst gekopieerde selectie: Ctrl+b ].

Dit is vooral nuttig als u een foutmelding uit een lang logbestand wilt overnemen zonder de muis te gebruiken — praktisch als u via een trage SSH-verbinding of een terminalvenster zonder muisondersteuning werkt.

Controlevraag

Uit Werkboek deel 16, Opdracht 16.3

1Genereer scrollback met ls -la /etc en dmesg, ga in copy mode (Ctrl+b [), scroll terug naar een regel uit dmesg, selecteer die regel en plak hem (Ctrl+b ]) achter de prompt.Toon antwoord
ls -la /etc
dmesg
# Ctrl+b [           -> copy mode aan
# PageUp / pijltjes   -> scrollen naar een dmesg-regel
# Space               -> selectie starten
# pijltjes            -> selectie uitbreiden
# Enter               -> kopiëren, copy mode sluit
# Ctrl+b ]            -> plakken
05

Een minimale tmux-configuratie

⏱ 8 min

Tmux leest bij het starten ~/.tmux.conf. Drie instellingen die de meeste gebruikers al vroeg toevoegen:

# ~/.tmux.conf
set -g mouse on              # muisscrollen en pane-selectie met de muis toestaan
set -g history-limit 10000   # meer scrollback dan de standaard 2000 regels
set -g base-index 1          # windows tellen vanaf 1 in plaats van 0

Na een wijziging herlaadt u de configuratie zonder de sessie te verlaten:

tmux source-file ~/.tmux.conf

De prefix-toets (Ctrl+b) is naar smaak te herbinden, bijvoorbeeld naar Ctrl+a (de klassieke screen-toets):

set -g prefix C-a
unbind C-b
bind C-a send-prefix
Fenna's advies aan Milan

Begin met de standaard prefix. Pas als u tientallen keren per dag in tmux werkt, weegt het herbinden op tegen de verwarring dat elke andere machine nog de standaardtoets gebruikt.

Controlevraag

Uit Werkboek deel 16, Opdracht 16.4

1Maak ~/.tmux.conf aan met minstens: mouse on, een aangepaste history-limit, en base-index 1. Herlaad de configuratie met tmux source-file zonder tmux te herstarten en controleer dat muisscrollen werkt.Toon antwoord
# ~/.tmux.conf
set -g mouse on
set -g history-limit 20000
set -g base-index 1
tmux source-file ~/.tmux.conf

Controlepunt: met de muis scrollen in een pane laat nu de geschiedenis zien in plaats van tekens in te voeren.
