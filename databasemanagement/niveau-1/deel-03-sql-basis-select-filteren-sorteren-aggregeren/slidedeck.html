Slide 5 — De vorm van een SELECT

SELECT   kolommen
FROM     tabellen
WHERE    rijfilter
GROUP BY groepering
HAVING   groepsfilter
ORDER BY sortering
LIMIT    aantal;

Dit is de schrijfvolgorde. Onthoud dat woord.

Slide 7 — Namen samenvoegen

Slide 10 — Twee valkuilen in WHERE

1. AND bindt sterker dan OR

WHERE land='BE' OR land='DE' AND einddatum IS NULL

→ altijd haakjes zetten

2. BETWEEN op timestamp

WHERE t >= '2025-01-01' AND t < '2026-01-01'

→ ondergrens inclusief, bovengrens exclusief

Slide 11 — Voorspel de uitkomst

SELECT count(*) FROM deelnemer;
SELECT count(*) FROM deelnemer WHERE woonplaats = 'Utrecht';
SELECT count(*) FROM deelnemer WHERE woonplaats <> 'Utrecht';

Notities: laat de zaal voorspellen dat 2 + 3 = 1. Toon dat het niet klopt.

Slide 12 — Waar zijn ze gebleven?

~240 deelnemers hebben geen woonplaats.

NULL <> 'Utrecht' is onbekend → WHERE laat alleen true door.

WHERE woonplaats IS DISTINCT FROM 'Utrecht'

Slide 31 — Aggregeren

count(*) — alle rijen count(kolom) — niet-NULL waarden count(DISTINCT kolom) — verschillende waarden

sum · avg · min · max — negeren NULL string_agg · array_agg

Slide 32 — FILTER

SELECT
  count(*)                                        AS totaal,
  count(*) FILTER (WHERE einddatum IS NULL)       AS actief,
  count(*) FILTER (WHERE bsn IS NULL)             AS zonder_bsn
FROM deelnemer;

Vier getallen. Eén scan. Eén moment.

Slide 33 — De GROUP BY-regel

Elke kolom in SELECT staat óf in GROUP BY, óf in een aggregatie.

SELECT sector, naam, count(*) FROM werkgever GROUP BY sector;
-- ERROR

Notities: laat de foutmelding staan en vraag: welke van de dertig namen zou er moeten staan?

Slide 34 — WHERE of HAVING

WHERE — filtert rijen, vóór het groeperen HAVING — filtert groepen, ná het groeperen

Aggregaties mogen alleen in HAVING. Alles wat per rij kan, hoort in WHERE.

Slide 35 — De uitvoeringsvolgorde

1. FROM / JOIN
2. WHERE
3. GROUP BY
4. HAVING
5. SELECT      ← hier ontstaan aliassen
6. DISTINCT
7. ORDER BY    ← hier mogen ze wél
8. LIMIT

Slide 36 — Wat daaruit volgt

  • Alias niet in WHERE → bestaat nog niet (stap 2 vóór 5)
  • Alias wél in ORDER BY → stap 7 ná 5
  • Geen aggregatie in WHERE → nog geen groepen

Eén schema verklaart de meeste beginnersfouten.
