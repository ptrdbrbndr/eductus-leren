Slide 6 — Opzetten

CREATE SERVER meridiaan_server
    FOREIGN DATA WRAPPER postgres_fdw
    OPTIONS (host '...', dbname 'meridiaan');

CREATE USER MAPPING FOR federatie_rapportage
    SERVER meridiaan_server OPTIONS (user '...', password '...');

Slide 7 — Foreign tables

IMPORT FOREIGN SCHEMA meridiaan_prod
    LIMIT TO (deelnemer, dienstverband)
    FROM SERVER meridiaan_server
    INTO federatie_meridiaan;

Gedraagt zich daarna als een gewone tabel.

Slide 10 — Pushdown

SELECT * FROM federatie_meridiaan.deelnemer WHERE deelnemer_id = 42;

De WHERE wordt meegestuurd naar de bron. Alleen de relevante rij komt terug.

Slide 11 — Voorspel

-- join tussen TWEE VERSCHILLENDE bronnen
SELECT m.achternaam, k.achternaam
FROM federatie_meridiaan.deelnemer m,
     federatie_kompas.deelnemer k
WHERE m.achternaam = k.achternaam;

Wordt deze join doorgeschoven?

Notities: laat de zaal gokken vóór het experiment.

Slide 12 — Nee.

Nested Loop
  ->  Foreign Scan on deelnemer m   -- hele tabel opgehaald
  ->  Foreign Scan on deelnemer k   -- hele tabel opgehaald
      (join lokaal, na ophalen)

Het federatieve equivalent van

een cross-shard-join (deel 24-25).

Slide 13 — Remote SQL

  Remote SQL: SELECT ... WHERE (deelnemer_id = 42)

Hetzelfde controleerbare signaal als Task Count (Citus) en pruning (partities).

Slide 15 — De federatieve rapportagelaag

CREATE VIEW deelnemers_per_fonds AS
SELECT 'Meridiaan', count(*) FROM federatie_meridiaan.deelnemer
UNION ALL
SELECT 'Kompas', count(*) FROM federatie_kompas.deelnemer
UNION ALL
SELECT 'Baken', count(*) FROM federatie_baken.deelnemer;

Elke tak: doorgeschoven naar zijn eigen bron.

op hun eigen drukste moment.

Slide 23 — Rechten over de grens

REVOKE ALL ON FOREIGN SERVER meridiaan_server FROM PUBLIC;
GRANT USAGE ON FOREIGN SERVER meridiaan_server TO federatie_rapportage;

Minimale leesrol op de bron. Geen BSN in de import. SSL verplicht — net als elke andere verbinding (deel 21).
